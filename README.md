# 我的教學影片網站

一個簡單的教學影片網站，不需要會寫程式也能維護。

## 一、讓網站上線（只要做一次）

1. 打開這個儲存庫的 GitHub 頁面
2. 點上方的 **Settings（設定）**
3. 左邊選單點 **Pages**
4. 在「Branch」選 **main**，資料夾選 **/ (root)**，按 **Save**
5. 等 1～2 分鐘，頁面上方會出現你的網址，像這樣：
   `https://你的帳號.github.io/zoo/`

## 二、新增影片

1. 先把影片上傳到 YouTube（可以設成「不公開」，只有知道連結的人看得到）
2. 在 GitHub 打開 **`videos.js`** 這個檔案
3. 點右上角的 ✏️ 鉛筆圖示（編輯）
4. 複製一段範例，改成你的影片標題、網址和分類，例如：

   ```js
   {
     title: "第一課：開始使用",
     youtube: "https://www.youtube.com/watch?v=你的影片代碼",
     category: "入門",
     description: "這一課會教你……",
   },
   ```

5. 按右上角綠色的 **Commit changes** 儲存
6. 等 1～2 分鐘，重新整理網站就會看到新影片

## 三、修改網站名稱

一樣在 `videos.js` 最下面，修改 `name`（網站名稱）和 `tagline`（標語）。

## 為什麼用 YouTube 放影片？

GitHub 不適合存放大型影片檔（單檔上限 100MB，而且會很慢）。
把影片放在 YouTube，再嵌入到這個網站，播放順暢又免費。

## 檔案說明

| 檔案 | 用途 | 需要改嗎？ |
|---|---|---|
| `videos.js` | 影片清單、網站名稱 | ✅ 平常只改這個 |
| `index.html` | 網頁架構 | 不用 |
| `style.css` | 外觀樣式 | 不用 |
| `app.js` | 網站運作程式 | 不用 |
